# Идеи на потом

Сюда записываются идеи, которые не входят в текущий этап.

- Отдельная задержка разворота для верхнего края (там вкладки браузера и заголовки окон) — если 300 мс окажется мало.
- Прятать полоску над полноэкранным окном на своём мониторе, даже когда активно окно на другом мониторе (сейчас, по спецификации, прячется только пока полноэкранное окно активно).
- Картинка-превью под курсором при перетаскивании снимка или файла наружу (`IDragSourceHelper`), как в Проводнике.
- Ссылка из браузера на полку (сохранять как `.url`) — сейчас принимаются только файлы и картинки.
- Кнопка «Удалить» в окне установки (сейчас удаление — по шагам из README).
- Подпись EdgeDock.exe сертификатом, чтобы Windows не предупреждала при первом запуске скачанного файла.
