# EdgeDock

Лёгкий виджет для Windows 11. Тонкая полоска у края экрана при наведении раскрывается
в панель с акриловым фоном: свежие скриншоты, полка файлов для перетаскивания, что сейчас
играет (включая Яндекс Музыку), громкость и переключение колонок, наушников и микрофона в один клик.
Виджет не забирает фокус, не виден в Alt+Tab и в простое почти не тратит процессор.

**[⬇ Скачать EdgeDock.exe](https://github.com/Fogufor/EdgeDock/releases/latest)** — один файл, ничего дополнительно ставить не нужно.

## Установка за минуту

1. Скачайте **EdgeDock.exe** по ссылке выше и запустите.
   Файл не подписан, поэтому Windows может показать «Windows защитила ваш компьютер» —
   нажмите «Подробнее» → «Выполнить в любом случае».
2. В окне установки выберите папку (можно оставить предложенную) и нажмите **«Установить и запустить»**.
   Галочки включают автозапуск вместе с Windows и ярлык в меню «Пуск».
3. Готово: полоска появится у верхнего края экрана по центру. Наведите на неё мышь — откроется панель.

Слушаете Яндекс Музыку в Яндекс Браузере? На последнем шаге окна установки нажмите
**«Открыть страницу расширений»** — путь к расширению скопируется сам, дальше три клика по подсказке.

**Обновление** — так же: скачайте новый EdgeDock.exe и запустите. Окно установки найдёт установленную
копию, закроет её и предложит «Обновить и запустить». Настройки и полка сохраняются.

> Файл большой (~160 МБ), потому что в него встроен .NET. На память это не влияет: виджет занимает около 25–40 МБ.

## Что умеет

- **Док.** Полоска у верхнего, левого или правого края экрана — или «таблетка» в любом месте.
  Панель открывается через 0,3 с наведения (случайное касание не срабатывает) и закрывается через 0,5 с
  после ухода мыши. Док перетаскивается: у края прилипает, положение запоминается.
- **Карман.** Лента последних скриншотов: клик открывает снимок, перетаскивание отдаёт его как файл —
  в Telegram, Outlook, Проводник. Полка: бросьте сюда файлы или картинки из браузера, чтобы потом перетащить дальше.
- **Музыка.** Что играет в Windows (Spotify, Chrome, Edge, плееры) и в Яндекс Музыке: обложка,
  «назад / пауза / вперёд» и полоска общей громкости.
- **Звук.** Избранные колонки, наушники и микрофоны — переключение в один клик.
  Кнопка «Созвон» переводит выход и микрофон на гарнитуру и возвращает обратно.
- **Незаметность.** Во время полноэкранной игры или видео виджет прячется и замирает.
  Светлая и тёмная тема и цвет акцента — как в Windows.
- **В планах:** ближайшая встреча из Outlook, закреплённые телефоны, теги и ссылки.

## Управление

Иконка виджета — в трее (Windows 11 прячет новые иконки под стрелку «^»,
её можно перетащить на панель задач). В меню иконки:

- **Закрепить положение** — чтобы случайно не сдвинуть док;
- **Вернуть на место** — к верхнему краю основного монитора;
- **Открыть настройки** / **Перезагрузить настройки**;
- **Открыть папку логов**;
- **Выход**.

## Настройки

Файл `%LocalAppData%\EdgeDock\settings.json` создаётся при первом запуске и правится руками
(«Открыть настройки» в меню трея). После правки — «Перезагрузить настройки».

Чтобы в блоке «Звук» появились ваши устройства, впишите их названия — как в панели звука Windows,
достаточно части названия:

```json
"audio": {
  "favoriteOutputs": ["Динамики (Realtek(R) Audio)", "Наушники"],
  "favoriteInputs": ["Микрофон"],
  "callMode": { "output": "Наушники", "input": "Микрофон" }
}
```

Остальные параметры — задержки, ширина панели, автозапуск, папка скриншотов — описаны в [SPEC.md](SPEC.md).

## Музыка из Яндекс Браузера

Яндекс Браузер не сообщает Windows, что в нём играет музыка, поэтому для него есть маленькое
расширение [`BrowserExtension`](BrowserExtension). Окно установки кладёт его в папку виджета
и помогает подключить. Вручную:

1. Откройте в Яндекс Браузере `browser://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку `BrowserExtension` в папке установки.
4. Обновите вкладку Яндекс Музыки (F5).

Расширение передаёт трек только виджету на этом компьютере (127.0.0.1). Подробнее —
в [BrowserExtension/README.md](BrowserExtension/README.md).

## Удаление

1. Меню трея → «Выход».
2. Удалите ярлыки `EdgeDock.lnk` из автозапуска (Win+R → `shell:startup`) и из меню «Пуск».
3. Удалите папку установки (по умолчанию `%LocalAppData%\Programs\EdgeDock`)
   и папку `%LocalAppData%\EdgeDock` (настройки, полка, кэш, логи).
4. Если подключали расширение — удалите его на странице `browser://extensions`.

## Для разработки

Нужен .NET 10 SDK (`winget install Microsoft.DotNet.SDK.10`).

- Запуск из исходников, без установки: `dotnet run --project EdgeDock/EdgeDock.csproj -c Release`.
- Собрать EdgeDock.exe и открыть окно установки: `powershell -ExecutionPolicy Bypass -File publish.ps1`
  (файл появится в папке `artifacts`).
- Выпустить версию: `git tag v1.2.3` и `git push origin v1.2.3` — GitHub сам соберёт EdgeDock.exe
  и выложит его в [Releases](https://github.com/Fogufor/EdgeDock/releases)
  (сценарий — `.github/workflows/release.yml`).

Устройство проекта:

- `EdgeDock/` — виджет: C#, .NET 10, WPF, [WPF UI](https://github.com/lepoco/wpfui),
  [NAudio](https://github.com/naudio/NAudio).
- `BrowserExtension/` — расширение для Яндекс Браузера.
- [SPEC.md](SPEC.md) — спецификация и принятые решения, [IDEAS.md](IDEAS.md) — идеи на потом.

Логи пишутся только при проблемах: `%LocalAppData%\EdgeDock\logs`.
