# EdgeDock

Лёгкий виджет для Windows 11. Тонкая полоска у края экрана при наведении раскрывается
в панель с акриловым фоном: свежие скриншоты, полка файлов для перетаскивания, текущая
музыка (включая Яндекс Музыку) и переключение колонок, наушников и микрофона в один клик.
Виджет не забирает фокус, не виден в Alt+Tab и в простое почти не тратит процессор.

## Что умеет

- **Док.** Полоска у верхнего, левого или правого края экрана или «таблетка» в любом месте.
  Панель открывается через 0,3 с наведения, закрывается через 0,5 с после ухода мыши.
  Док можно перетащить: у края он прилипает, положение запоминается.
- **Карман.** Лента последних скриншотов из папки «Снимки экрана»: клик открывает снимок,
  перетаскивание отдаёт его как файл (в Telegram, Outlook, Проводник). Полка — сюда можно
  бросить файлы и картинки из браузера, чтобы потом перетащить дальше.
- **Музыка.** Что играет в Windows (Spotify, Chrome, Edge и др.), обложка и кнопки
  «назад / пауза / вперёд». Для Яндекс Музыки в Яндекс Браузере — отдельное расширение.
- **Звук.** Избранные выходы и микрофоны, переключение в один клик. Кнопка «Созвон»
  переключает выход и микрофон на гарнитуру и возвращает обратно.
- **В планах:** ближайшая встреча из Outlook 2013, закреплённые телефоны, теги и ссылки.

## Установка

Нужна только Windows 11 — всё остальное уже внутри файла.

1. Скачайте **EdgeDock.exe** со страницы
   [последнего выпуска](https://github.com/Fogufor/EdgeDock/releases/latest).
2. Запустите его. Файл не подписан, поэтому Windows может показать «Windows защитила ваш компьютер» —
   нажмите «Подробнее» → «Выполнить в любом случае».
3. В окне установки выберите папку (можно оставить предложенную) и нажмите **«Установить и запустить»**.
   Галочки ниже включают автозапуск вместе с Windows и ярлык в меню «Пуск».
4. Готово: полоска появится у верхнего края экрана по центру. Наведите на неё мышь — откроется панель.
5. По желанию, там же в окне — **музыка из Яндекс Браузера**: кнопка «Открыть страницу расширений»
   откроет нужную страницу и скопирует путь к расширению, дальше три клика по подсказке.

**Обновление** — то же самое: скачайте новый EdgeDock.exe и запустите. Окно установки само найдёт
установленную копию, закроет её и предложит «Обновить и запустить». Настройки и полка сохраняются.

Файл большой (~160 МБ), потому что в него встроен .NET — ставить его отдельно не нужно.
На память это не влияет: виджет занимает около 25–40 МБ.

## Управление

Иконка виджета — в трее (Windows 11 прячет новые иконки под стрелку «^»,
её можно перетащить на панель задач). В меню иконки:

- **Закрепить положение** — чтобы случайно не сдвинуть док;
- **Вернуть на место** — к верхнему краю основного монитора;
- **Открыть настройки** / **Перезагрузить настройки**;
- **Открыть папку логов**;
- **Выход**.

## Настройки

Файл `%LocalAppData%\EdgeDock\settings.json` создаётся при первом запуске и правится руками.
После правки — «Перезагрузить настройки» в меню трея. Пример секции звука
(названия устройств — как в панели звука Windows, достаточно части названия):

```json
"audio": {
  "favoriteOutputs": ["Динамики (Realtek(R) Audio)", "Наушники"],
  "favoriteInputs": ["Микрофон"],
  "callMode": { "output": "Наушники", "input": "Микрофон" }
}
```

Остальные параметры (задержки, ширина панели, автозапуск, папка скриншотов) описаны
в [SPEC.md](SPEC.md). Положение дока и содержимое полки виджет сам хранит в `state.json` рядом.

## Музыка из Яндекс Браузера

Яндекс Браузер не сообщает Windows, что в нём играет музыка, поэтому для него есть
расширение [`BrowserExtension`](BrowserExtension). Окно установки кладёт его рядом с виджетом
(`<папка установки>\BrowserExtension`) и помогает подключить. Вручную:

1. Откройте в Яндекс Браузере `browser://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку `BrowserExtension`.
4. Обновите вкладку Яндекс Музыки (F5).

Подробнее — в [BrowserExtension/README.md](BrowserExtension/README.md).

## Удаление

1. Меню трея → «Выход».
2. Удалите ярлыки `EdgeDock.lnk` из папки автозапуска (Win+R → `shell:startup`) и из меню «Пуск».
3. Удалите папку установки (по умолчанию `%LocalAppData%\Programs\EdgeDock`)
   и папку `%LocalAppData%\EdgeDock` (настройки, полка, кэш, логи).
4. Если подключали расширение — удалите его на странице `browser://extensions`.

## Для разработки

Нужен .NET 10 SDK (`winget install Microsoft.DotNet.SDK.10`).

- Запуск из исходников, без установки: `dotnet run --project EdgeDock/EdgeDock.csproj -c Release`.
- Собрать EdgeDock.exe и открыть окно установки: `powershell -ExecutionPolicy Bypass -File publish.ps1`
  (файл появится в папке `artifacts`).
- Выпустить версию: `git tag v1.2.3` и `git push origin v1.2.3` — GitHub сам соберёт EdgeDock.exe
  и выложит его в [Releases](https://github.com/Fogufor/EdgeDock/releases)
  (сценарий — `.github/workflows/release.yml`).

## Устройство проекта

- `EdgeDock/` — виджет: C#, .NET 10, WPF, [WPF UI](https://github.com/lepoco/wpfui),
  [NAudio](https://github.com/naudio/NAudio).
- `BrowserExtension/` — расширение для Яндекс Браузера.
- [SPEC.md](SPEC.md) — спецификация и принятые решения, [IDEAS.md](IDEAS.md) — идеи на потом.

Логи пишутся только при проблемах: `%LocalAppData%\EdgeDock\logs`.
