# EdgeDock

Лёгкий виджет для Windows 11. Тонкая полоска у края экрана при наведении раскрывается
в панель с акриловым фоном: свежие скриншоты, полка файлов для перетаскивания, текущая
музыка (включая Яндекс Музыку) и переключение колонок, наушников и микрофона в один клик.
Виджет не забирает фокус, не виден в Alt+Tab и в простое почти не тратит процессор.

## Что умеет

- **Док.** Полоска у верхнего, левого или правого края экрана или «таблетка» в любом месте.
  Панель открывается через 0,3 с наведения, закрывается через 0,5 с после ухода мыши.
  Док можно перетащить: у края он прилипает, положение запоминается.
- **Карман.** Лента последних скриншотов из папки «Снимки экрана»: клик открывает снимок,
  перетаскивание отдаёт его как файл (в Telegram, Outlook, Проводник). Полка — сюда можно
  бросить файлы и картинки из браузера, чтобы потом перетащить дальше.
- **Музыка.** Что играет в Windows (Spotify, Chrome, Edge и др.), обложка и кнопки
  «назад / пауза / вперёд». Для Яндекс Музыки в Яндекс Браузере — отдельное расширение.
- **Звук.** Избранные выходы и микрофоны, переключение в один клик. Кнопка «Созвон»
  переключает выход и микрофон на гарнитуру и возвращает обратно.
- **В планах:** ближайшая встреча из Outlook 2013, закреплённые телефоны, теги и ссылки.

## Что нужно

- Windows 11.
- .NET 10 SDK — для сборки. Проще всего поставить через winget:

  ```powershell
  winget install Microsoft.DotNet.SDK.10
  ```

## Установка и запуск

1. Скачайте проект:

   ```powershell
   git clone https://github.com/Fogufor/EdgeDock.git
   cd EdgeDock
   ```

2. Установите виджет:

   ```powershell
   powershell -ExecutionPolicy Bypass -File publish.ps1
   ```

   Скрипт соберёт виджет в `%LocalAppData%\Programs\EdgeDock`, запустит его и добавит
   в автозапуск (ярлык в папке `shell:startup`). Если виджет уже запущен, скрипт закроет
   его и поставит новую версию — так же обновляется виджет после `git pull`.

3. Полоска появится у верхнего края экрана по центру. Наведите на неё мышь — откроется панель.

Просто попробовать, ничего не устанавливая и не трогая автозапуск:

```powershell
dotnet run --project EdgeDock/EdgeDock.csproj -c Release
```

## Управление

Иконка виджета — в трее (Windows 11 прячет новые иконки под стрелку «^»,
её можно перетащить на панель задач). В меню иконки:

- **Закрепить положение** — чтобы случайно не сдвинуть док;
- **Вернуть на место** — к верхнему краю основного монитора;
- **Открыть настройки** / **Перезагрузить настройки**;
- **Открыть папку логов**;
- **Выход**.

## Настройки

Файл `%LocalAppData%\EdgeDock\settings.json` создаётся при первом запуске и правится руками.
После правки — «Перезагрузить настройки» в меню трея. Пример секции звука
(названия устройств — как в панели звука Windows, достаточно части названия):

```json
"audio": {
  "favoriteOutputs": ["Динамики (Realtek(R) Audio)", "Наушники"],
  "favoriteInputs": ["Микрофон"],
  "callMode": { "output": "Наушники", "input": "Микрофон" }
}
```

Остальные параметры (задержки, ширина панели, автозапуск, папка скриншотов) описаны
в [SPEC.md](SPEC.md). Положение дока и содержимое полки виджет сам хранит в `state.json` рядом.

## Музыка из Яндекс Браузера

Яндекс Браузер не сообщает Windows, что в нём играет музыка, поэтому для него есть
расширение в папке [`BrowserExtension`](BrowserExtension):

1. Откройте в Яндекс Браузере `browser://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку `BrowserExtension`.
4. Обновите вкладку Яндекс Музыки (F5).

Подробнее — в [BrowserExtension/README.md](BrowserExtension/README.md).

## Удаление

1. Меню трея → «Выход».
2. Удалите ярлык `EdgeDock.lnk` из папки автозапуска (Win+R → `shell:startup`).
3. Удалите папки `%LocalAppData%\Programs\EdgeDock` (программа)
   и `%LocalAppData%\EdgeDock` (настройки, полка, кэш, логи).
