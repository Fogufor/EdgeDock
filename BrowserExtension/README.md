# Расширение «EdgeDock — Яндекс Музыка»

Яндекс Браузер не сообщает Windows, что в нём играет музыка, поэтому виджет не видит её сам.
Это расширение читает трек во вкладке Яндекс Музыки (название, обложку, позицию, лайк) и передаёт
его виджету, а кнопки «назад / пауза / вперёд», перемотку и «Нравится» из виджета выполняет на странице.

## Установка (один раз)

1. Откройте в Яндекс Браузере `browser://extensions`.
2. Включите «Режим разработчика» (переключатель вверху страницы).
3. Нажмите «Загрузить распакованное расширение» и выберите эту папку (`BrowserExtension`).
4. Проверьте ID расширения: он должен быть `bihfedgclefgkpmnhbocgepnjkidjlki`.
   Виджет принимает подключения только от этого ID.

Вкладки Яндекс Музыки, открытые до установки, нужно обновить (F5).

## Как это устроено

* `content.js` работает во вкладке Яндекс Музыки: берёт название, исполнителя, обложку и
  «играет / пауза» из Media Session (её заполняет сам плеер), позицию и длину — из полоски
  перемотки плеера («Управление таймкодом»), лайк — из кнопки «Нравится» (`aria-pressed`).
  Раз в секунду сверяет, не сменился ли трек; позицию отдельно не шлёт — виджет досчитывает её
  сам, а о перемотке расширение сообщает сразу. Элементы плеера ищет по подписям (`aria-label`) —
  если Яндекс их переименует, поправить `BUTTONS` и `TIMELINE` в начале файла.
* `background.js` выбирает вкладку, где играет (или играла последней), и отправляет виджету
  только изменения по WebSocket на `ws://127.0.0.1:48620/`. Виджет не запущен — пробует
  подключиться не чаще раза в 10 секунд.
* Ключ `key` в `manifest.json` закрепляет ID расширения. Не меняйте его — иначе виджет
  перестанет пускать расширение (ID записан в `BrowserMusicBridge.cs`).

## Обновление

После правок в этой папке нажмите «Обновить» у расширения на странице `browser://extensions`
и обновите вкладку Яндекс Музыки.
